Gemini API 키 무료 발급 가이드

  1. Google AI Studio 이동:
    https://aistudio.google.com/app/apikey
  2. Create API Key 버튼을 눌러 새로운 키 생성
  3. 생성된 키(AIzaSy...)를 복사하여 상단 키 입력창에 저장

GitHub Pages 무료 배포 방법

  1. GitHub 저장소 생성: GitHub에서 새 public repository 생성
  2. index.html 파일 업로드: 다운로드받은 이 index.html 파일 하나만 업로드
  3. Pages 설정 활성화: Settings -> Pages -> Branch를 main (또나 master)으로 설정 후 Save
  4. 배포 완료: 약 1분 후 부여된 무료 https://username.github.io/repo-name 주소로 접근 가능!
