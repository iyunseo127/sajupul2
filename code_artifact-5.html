Gemini API 키 무료 발급 방법

  1. Google AI Studio 로그인:
    https://aistudio.google.com/app/apikey
  2. API 키 생성:
    파란색 "Create API Key" 버튼을 클릭합니다.
  3. 키 복사 및 입력:
    생성된 API 키(AIzaSy...)를 복사하여 상단 입력창에 저장하세요.

사용자의 API 키는 서버에 저장되지 않고 오직 개인 브라우저 내부(LocalStorage)에만 안전하게 유지됩니다.
