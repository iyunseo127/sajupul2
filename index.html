Gemini API 키 설정

Google AI Studio에서 발급받은 API 키를 입력해주세요. 입력된 키는 서버에 저장되지 않고 본인의 **브라우저(Local Storage)**에만 안전하게 보관됩니다.

무료 Gemini API 키 발급 가이드

  1. Google AI Studio 접속:
    aistudio.google.com/app/apikey 에 구글 계정으로 로그인합니다.
  2. API 키 생성:
    화면 상단의 "Create API key" 버튼을 클릭합니다.
  3. 프로젝트 선택 및 복사:
    기존 Google Cloud 프로젝트를 선택하거나 새 프로젝트를 자동 생성한 후 복사된 `AIzaSy...` 형태의 키 문자열을 복사합니다.
  4. 본 웹 앱에 입력:
    [API 키 설정] 창을 열고 복사한 키를 붙여넣고 저장하세요! (무료 티어로 매월 충분하게 무료 사용 가능합니다)

GitHub Pages 1분 배포법

이 소스코드는 단 하나의 index.html 파일로 구성되어 있어 GitHub Pages로 1분 만에 무료 라이브 웹사이트 배포가 가능합니다.

1. Repositories 생성: GitHub.com에서 New Repository 생성 (예: saju-analysis)

2. 파일 업로드: 이 파일의 전체 코드를 복사하여 index.html 로 파일 생성 및 Commit.

3. Pages 활성화: 저장소 Settings -> Pages -> Branch를 'main' 및 / (root) 선택 후 Save!
